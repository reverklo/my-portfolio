☁️ เปิดใช้งาน Cloud Firestore

คุณได้สร้าง Firebase Project แล้ว แต่ยังไม่ได้เปิดใช้งานฐานข้อมูล Firestore Database จึงทำให้ระบบยังไม่สามารถบันทึกข้อมูลและรูปภาพขึ้น Cloud เพื่ออัปเดตแบบเรียลไทม์ได้

📌 วิธีเปิดใช้งาน (ทำเพียง 1 นาที):
  1. สลับไปที่แท็บ Firebase Console (โปรเจกต์ my-portfolio-db) ที่เปิดอยู่
  2. ที่แถบเมนูด้านซ้าย เลือกเมนู Firestore Database
  3. คลิกปุ่มสีส้ม "Create database" (สร้างฐานข้อมูล)
  4. เลือก Location (ใช้ค่าเริ่มต้นได้เลย) แล้วกด Next
  5. เลือก "Start in test mode" (เริ่มต้นในโหมดทดสอบ) แล้วกด Enable
